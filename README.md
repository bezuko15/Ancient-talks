# Ancient Talk

Static website for Ancient Talk: public-domain texts of the Church Fathers and classic Christian writers, free to read in the browser and download.

- **Home** (`index.html`) introduces the project.
- **Library** (`library.html`) searches the catalog by title, author, and era.
- **Reader** (`books/`) serves each work, with EPUB and plain-text files under `books/files/`.
- **Authors, Watch, and About** cover the writers, YouTube readings, and the project.

GitHub Pages serves this site from the root of `main`. The empty `.nojekyll` file keeps Jekyll from rewriting the pages.
